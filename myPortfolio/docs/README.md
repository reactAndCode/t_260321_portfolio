# 포트폴리오 사이트 문서 인덱스

이 폴더는 GitHub Pages 기반 개발자 포트폴리오 사이트의 분석, 설계, 사용 방법을 정리한 문서 모음입니다.

## 문서 목록

- [01_요구사항분석.md](./01_%EC%9A%94%EA%B5%AC%EC%82%AC%ED%95%AD%EB%B6%84%EC%84%9D.md)
  - 사이트 목표, 대상 사용자, 주요 요구사항, 기능/비기능 요구사항을 정리한 문서
- [02_구현설계서_task.md](./02_%EA%B5%AC%ED%98%84%EC%84%A4%EA%B3%84%EC%84%9C_task.md)
  - 구현 단위 태스크, 페이지별 설계, 데이터 구조, 공통 스크립트 동작 방식을 정리한 문서
- [03_사용자매뉴얼.md](./03_%EC%82%AC%EC%9A%A9%EC%9E%90%EB%A7%A4%EB%89%B4%EC%96%BC.md)

## 문서 활용 순서

1. 요구사항과 목적을 먼저 확인하려면 `01_요구사항분석.md`를 읽습니다.
2. 실제 구현 구조와 작업 단위를 이해하려면 `02_구현설계서_task.md`를 읽습니다.
3. 실제 운영, 수정, 배포 방법을 확인하려면 `03_사용자매뉴얼.md`를 읽습니다.
