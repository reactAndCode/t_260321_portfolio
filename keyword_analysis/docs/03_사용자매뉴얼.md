# 네이버 키워드 분석 웹사이트 사용자 매뉴얼

## 1. 개요
- 본 매뉴얼은 `Keyword Pulse` 웹사이트를 실행하고 사용하는 방법을 설명한다.
- 현재 버전은 네이버 키워드 분석용 MVP이며, 실데이터 또는 mock 데이터 기반으로 동작한다.

## 2. 주요 기능
- 키워드 검색
- 월간 검색량 확인
- 최근 검색 추이 확인
- 연관 키워드 확인
- 자동 인사이트 확인

## 3. 실행 전 준비
### 3.1 필수 프로그램
- Node.js
- npm

### 3.2 프로젝트 설치
프로젝트 루트에서 아래 명령을 실행한다.

```powershell
npm install
```

## 4. 환경변수 설정
실데이터 연동을 원하면 프로젝트 루트에 `.env.local` 파일을 생성하고 아래 값을 설정한다.

```env
NAVER_SEARCHAD_ACCESS_KEY=your_access_key
NAVER_SEARCHAD_SECRET_KEY=your_secret_key
NAVER_SEARCHAD_CUSTOMER_ID=your_customer_id
NAVER_DATALAB_CLIENT_ID=your_client_id
NAVER_DATALAB_CLIENT_SECRET=your_client_secret
```

### 참고
- 환경변수를 설정하지 않아도 사이트는 실행된다.
- 이 경우 mock 데이터로 동작한다.

## 5. 실행 방법
개발 서버 실행:

```powershell
npm run dev
```

브라우저에서 아래 주소로 접속한다.

```text
http://localhost:3000
```

## 6. 화면 사용 방법
### 6.1 첫 화면
- 페이지에 접속하면 예시 키워드 `문래동 미술학원` 분석 결과가 자동으로 표시된다.
- 우측 또는 상단 검색 영역에서 다른 키워드를 입력할 수 있다.

### 6.2 키워드 검색
1. 검색창에 분석할 키워드를 입력한다.
2. `분석 시작` 버튼을 클릭한다.
3. 로딩 후 결과 대시보드가 갱신된다.

### 6.3 결과 확인
#### 검색량 카드
- `월간 PC 검색량`
- `월간 모바일 검색량`
- `월간 총 검색량`

#### 검색 추이
- 최근 12개월 기준으로 검색 흐름을 간단한 선형 차트로 표시한다.

#### 빠른 인사이트
- 검색량, 모바일 비중, 연관 키워드, 추세를 기반으로 요약 문장을 보여준다.

#### 연관 키워드
- 확장 가능한 키워드 후보를 표 형태로 보여준다.
- 월간 검색량과 경쟁도를 함께 확인할 수 있다.

## 7. 결과 해석 가이드
### 7.1 월간 총 검색량
- 높을수록 기본 수요가 큰 키워드일 가능성이 높다.
- 단, 실제 전환율과는 별개이므로 콘텐츠 목적에 맞는 추가 검토가 필요하다.

### 7.2 모바일 검색량 비중
- 모바일이 높으면 모바일 랜딩 경험이 중요할 수 있다.
- 짧고 빠르게 소비되는 콘텐츠 전략과 잘 맞는지 확인한다.

### 7.3 검색 추이
- 우상향이면 최근 관심도가 높아지는 흐름일 수 있다.
- 우하향이면 세부 키워드 확장이나 다른 주제 전환을 검토한다.

### 7.4 연관 키워드
- 메인 키워드 하나만 보기보다 연관 키워드 묶음으로 콘텐츠나 광고 전략을 세우는 데 활용한다.

## 8. 운영 모드 안내
### 8.1 Live 모드
- 네이버 API 환경변수가 설정된 경우
- 대시보드 우측 상단에 `Live Naver Data`가 표시된다.

### 8.2 Mock 모드
- 환경변수가 없거나 실데이터를 사용할 수 없는 경우
- 대시보드 우측 상단에 `Mock Preview`가 표시된다.
- 데모, UI 검토, 내부 개발 용도로 적합하다.

## 9. 오류 대응
### 9.1 키워드를 입력하지 않은 경우
- `키워드를 입력해 주세요.` 메시지가 표시된다.

### 9.2 외부 API 오류
- 서버에서 오류 메시지를 반환하면 화면 상단에 오류 패널이 표시된다.
- 환경변수 값과 네이버 API 권한 상태를 확인한다.

### 9.3 데이터가 없는 경우
- 추이 데이터가 없으면 빈 상태 문구가 표시된다.
- 연관 키워드가 없으면 표 대신 안내 메시지가 표시된다.
