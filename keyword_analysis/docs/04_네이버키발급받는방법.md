# 네이버 API 키 발급 방법

## 1. 문서 목적
- 본 문서는 `keyword_analysis` 프로젝트에서 사용하는 네이버 API 키 발급 절차를 정리한 문서이다.
- 본 프로젝트는 두 종류의 네이버 API 자격정보를 사용한다.
  - `NAVER_SEARCHAD_*`: 네이버 검색광고 API용
  - `NAVER_DATALAB_*`: NAVER Developers DataLab 검색어트렌드 API용

## 2. 왜 키가 2종류인가
- 네이버 검색광고 API와 네이버 DataLab API는 같은 네이버 서비스 계열이지만 발급 시스템이 다르다.
- 검색광고 API는 `네이버 검색광고 시스템`에서 발급한다.
- DataLab API는 `NAVER Developers`에서 발급한다.
- 따라서 아래 5개 환경변수가 필요하다.

```env
NAVER_SEARCHAD_ACCESS_KEY=
NAVER_SEARCHAD_SECRET_KEY=
NAVER_SEARCHAD_CUSTOMER_ID=
NAVER_DATALAB_CLIENT_ID=
NAVER_DATALAB_CLIENT_SECRET=
```

## 3. NAVER_SEARCHAD 발급 방법

### 3.1 필요한 값
- `NAVER_SEARCHAD_ACCESS_KEY`
- `NAVER_SEARCHAD_SECRET_KEY`
- `NAVER_SEARCHAD_CUSTOMER_ID`

### 3.2 공식 URL
- 네이버 검색광고 센터: https://searchad.naver.com
- 네이버 검색광고 관리화면: https://manage.searchad.naver.com
- 검색광고 API 도움말: https://ads.naver.com/help/faq/302
- 검색광고 API 문서: https://naver.github.io/searchad-apidoc/
- 검색광고 API GitHub 문서 저장소: https://github.com/naver/searchad-apidoc

### 3.3 사전 조건
- 네이버 계정이 있어야 한다.
- 네이버 검색광고 시스템 가입이 완료되어 있어야 한다.
- 광고주 또는 파트너사 계정으로 광고 시스템에 접근 가능해야 한다.

### 3.4 발급 절차
#### 1단계: 검색광고 시스템 로그인
1. 브라우저에서 `https://searchad.naver.com` 또는 `https://manage.searchad.naver.com`에 접속한다.
2. 네이버 계정으로 로그인한다.
3. 아직 검색광고를 사용한 적이 없다면 가입 절차를 완료한다.

#### 2단계: API 사용 관리 메뉴 이동
1. 로그인 후 검색광고 관리 화면으로 진입한다.
2. 상단 또는 관리 메뉴에서 `도구` 영역을 찾는다.
3. `API 사용 관리` 메뉴로 이동한다.

#### 3단계: API 사용 신청
1. `네이버 검색광고 API 서비스 신청` 또는 유사한 버튼을 클릭한다.
2. API 사용 관련 약관과 안내를 확인한다.
3. 신청을 완료한다.

#### 4단계: 키 확인
신청 완료 후 아래 값을 확인할 수 있다.
- `Access License`
- `Secret Key`

또한 계정 정보에서 아래 값을 확인한다.
- `Customer ID`

### 3.5 환경변수 매핑
- `NAVER_SEARCHAD_ACCESS_KEY` = `Access License`
- `NAVER_SEARCHAD_SECRET_KEY` = `Secret Key`
- `NAVER_SEARCHAD_CUSTOMER_ID` = `Customer ID`

예시:

```env
NAVER_SEARCHAD_ACCESS_KEY=xxxxxxxxxxxxxxxx
NAVER_SEARCHAD_SECRET_KEY=xxxxxxxxxxxxxxxx
NAVER_SEARCHAD_CUSTOMER_ID=1234567
```

### 3.6 프로젝트에서 사용하는 방식
- SearchAd API는 `keywordstool` 엔드포인트 호출에 사용된다.
- 현재 프로젝트에서는 아래 정보를 얻는 데 사용한다.
  - 월간 PC 검색량
  - 월간 모바일 검색량
  - 연관 키워드
  - 경쟁도

### 3.7 주의사항
- SearchAd 키는 NAVER Developers에서 발급받는 키가 아니다.
- `Client ID / Client Secret`과 혼동하면 안 된다.
- SearchAd는 광고 계정 권한이 있어야 한다.
- Secret Key는 외부에 노출하면 안 된다.
- Access License와 Customer ID도 서버 환경변수로만 관리하는 것이 안전하다.

### 3.8 발급 후 확인 포인트
- API 신청이 실제로 완료되었는지 확인
- 계정에 API 사용 권한이 있는지 확인
- Access License와 Secret Key를 복사할 때 공백이 들어가지 않았는지 확인
- Customer ID가 다른 광고계정 값과 혼동되지 않았는지 확인

## 4. NAVER_DATALAB 발급 방법

### 4.1 필요한 값
- `NAVER_DATALAB_CLIENT_ID`
- `NAVER_DATALAB_CLIENT_SECRET`

### 4.2 공식 URL
- NAVER Developers 메인: https://developers.naver.com
- NAVER Open API 공통 가이드: https://developers.naver.com/docs/common/openapiguide
- DataLab 검색어트렌드 API 문서: https://developers.naver.com/docs/serviceapi/datalab/search/search.md

### 4.3 사전 조건
- 네이버 계정이 있어야 한다.
- NAVER Developers 이용 약관 동의가 필요하다.
- 최초 등록 시 휴대폰 인증 또는 기본 정보 입력이 필요할 수 있다.

### 4.4 발급 절차
#### 1단계: NAVER Developers 로그인
1. `https://developers.naver.com`에 접속한다.
2. 네이버 계정으로 로그인한다.

#### 2단계: 애플리케이션 등록
1. 상단 메뉴 또는 대시보드에서 `Application` 메뉴로 이동한다.
2. `애플리케이션 등록`을 선택한다.
3. 처음 사용하는 계정이면 약관 동의, 인증, 기본 정보 입력을 진행한다.

#### 3단계: 앱 정보 입력
1. 애플리케이션 이름을 입력한다.
2. 설명이 필요하면 프로젝트 식별이 쉬운 이름으로 작성한다.
3. `사용 API` 선택 항목에서 `DataLab` 또는 `검색어트렌드` 관련 API를 선택한다.

#### 4단계: 비로그인 오픈 API 환경 추가
1. `비로그인 오픈 API 서비스 환경` 항목을 추가한다.
2. 필요한 기본 정보를 입력한다.
3. 저장 또는 등록을 완료한다.

#### 5단계: 키 확인
등록 완료 후 `내 애플리케이션` 화면에서 다음 값을 확인한다.
- `Client ID`
- `Client Secret`

### 4.5 환경변수 매핑
- `NAVER_DATALAB_CLIENT_ID` = `Client ID`
- `NAVER_DATALAB_CLIENT_SECRET` = `Client Secret`

예시:

```env
NAVER_DATALAB_CLIENT_ID=xxxxxxxxxxxxxxxx
NAVER_DATALAB_CLIENT_SECRET=xxxxxxxxxxxxxxxx
```

### 4.6 프로젝트에서 사용하는 방식
- DataLab API는 검색어 추이 데이터를 가져오는 데 사용한다.
- 현재 프로젝트에서는 아래 정보를 얻는 데 사용한다.
  - 최근 12개월 검색 추이

### 4.7 주의사항
- DataLab 키는 검색광고 API 키와 다르다.
- DataLab은 `Client ID / Client Secret` 구조이고, SearchAd는 `Access License / Secret Key / Customer ID` 구조이다.
- 앱 등록 시 선택한 API에 `검색어트렌드`가 포함되지 않으면 호출 시 오류가 날 수 있다.
- `Client Secret` 역시 외부에 노출하면 안 된다.

### 4.8 발급 후 확인 포인트
- 애플리케이션이 정상 등록되었는지 확인
- 사용 API 설정에 DataLab 검색어트렌드가 포함되었는지 확인
- 복사 시 줄바꿈이나 공백이 들어가지 않았는지 확인

## 5. 프로젝트 적용 방법

### 5.1 `.env.local` 생성
프로젝트 루트에 `.env.local` 파일을 생성한다.

### 5.2 값 입력
아래 형식으로 값을 넣는다.

```env
NAVER_SEARCHAD_ACCESS_KEY=발급받은_access_license
NAVER_SEARCHAD_SECRET_KEY=발급받은_secret_key
NAVER_SEARCHAD_CUSTOMER_ID=검색광고_customer_id

NAVER_DATALAB_CLIENT_ID=발급받은_client_id
NAVER_DATALAB_CLIENT_SECRET=발급받은_client_secret
```

### 5.3 실행

```powershell
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속한다.

## 6. 동작 규칙
- SearchAd 관련 값 3개가 모두 있으면 검색량/연관 키워드 실데이터를 조회한다.
- DataLab 관련 값 2개가 모두 있으면 검색 추이 실데이터를 조회한다.
- 둘 다 없으면 mock 데이터 모드로 동작한다.
- 일부만 설정된 경우 설정된 API만 실데이터로 동작하고 나머지는 빈 값 또는 fallback 상태가 될 수 있다.

## 7. 장애 발생 시 점검 항목

### 7.1 SearchAd가 동작하지 않을 때
- 검색광고 API 사용 신청이 완료되었는지 확인
- Access License, Secret Key, Customer ID가 정확한지 확인
- 해당 계정이 올바른 광고 계정인지 확인
- SearchAd API 문서의 서명 방식과 헤더 구성이 맞는지 확인

### 7.2 DataLab이 동작하지 않을 때
- NAVER Developers 앱이 정상 등록되었는지 확인
- 앱 설정에서 DataLab 검색어트렌드 API가 활성화되었는지 확인
- Client ID, Client Secret 값이 정확한지 확인
- 호출 한도나 권한 제한이 있는지 확인

### 7.3 공통 점검
- `.env.local` 파일 위치가 프로젝트 루트인지 확인
- 값 입력 후 개발 서버를 재시작했는지 확인
- 환경변수명 오타가 없는지 확인

## 8. 자주 헷갈리는 차이점

| 구분 | SearchAd | DataLab |
| --- | --- | --- |
| 발급 위치 | 네이버 검색광고 시스템 | NAVER Developers |
| 사용 목적 | 검색량, 연관 키워드, 경쟁도 | 검색 추이 |
| 필요한 값 | Access License, Secret Key, Customer ID | Client ID, Client Secret |
| 현재 프로젝트 사용 위치 | `lib/naver-searchad.ts` | `lib/naver-datalab.ts` |

## 9. 보안 권장사항
- `.env.local`은 git에 커밋하지 않는다.
- 운영 서버에서는 배포 플랫폼의 비밀변수 기능을 사용한다.
- 키가 노출되었다고 의심되면 즉시 재발급한다.
- 브라우저 클라이언트 코드에 키를 직접 넣지 않는다.
